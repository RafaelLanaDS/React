Resumo: React useState Hook
O useState é um dos principais hooks do React, e seu propósito fundamental é gerenciar valores (estado) dentro de um componente.

1. Conceito Principal
Re-renderização: Diferente de variáveis comuns (como o let userName no seu código), quando um valor gerenciado pelo useState é alterado, o React re-renderiza o componente para atualizar a interface com o novo dado.

Sintaxe Básica: const [nomeDoEstado, funcaoQueAtualiza] = useState(valorInicial)

No seu código, const [name, setName] = useState('João') cria um estado name que começa como "João". Para mudá-lo, você usa a função setName('Lucas'), o que fará a tela ser atualizada.

2. Uso do useState com Inputs (Formulários)
Atrelar o useState a campos de input é uma prática essencial no React para capturar e controlar dados digitados pelo usuário.

Evento onChange: A alteração do estado ocorre através do evento onChange do input.

Exemplo Prático (Seu código):

Você define o estado: const [age, setAge] = useState(18)

Você vincula o estado ao input: <input type="number" value={age} onChange={(e) => setAge(parseInt(e.target.value))} />

Toda vez que o usuário digita, o onChange captura o valor (e.target.value), converte para inteiro e atualiza o estado age.

Inputs Controlados (Controlled Inputs): Essa técnica garante que o React seja a única fonte de verdade para aquele dado, facilitando a limpeza dos campos após o uso ou a união de vários estados para envio ao back-end (como exemplificado na sua função handleSubmit).

3. Estrutura de Componentes
O arquivo Home.js demonstra como a componentização funciona na prática. O componente HookUseState (que contém toda a lógica de estado) é simplesmente importado e renderizado dentro da página principal (<HookUseState/>), mantendo o código organizado e modular.
